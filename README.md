# Astrivo Shorts renderer
3D Shorts renderer (three.js in headless Chrome, composited by ffmpeg).
Setup: `npm install` (installs three). Run: `PAGE=real3d.html node render3d.mjs scenes/real_earth.json out.mp4`
Pages: real3d.html (space), street3d.html (mannequin street), scene3d.html (cartoon, old).
